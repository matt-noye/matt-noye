## Flagship project
### Tollaro
A self-hosted WHMCS alternative for hosting providers, MSPs, and agencies that resell hosting, Microsoft 365, and VoIP.

- Self-hosted, sold on an annual licence. Your data stays on your infrastructure
- Full WHMCS import, with an optional dry run before you switch over
- Built with Laravel, and running MWN Digital's own client billing in production

Currently in open beta. 👉 https://tollaro.com

### Stratum
A native macOS database GUI built with SwiftUI. Fast, lightweight, and free.

👉 https://stratum.mwn-digital.uk

*Previously: SimpliSuite, a modular business management platform for SMEs.*
